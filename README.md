## 10 Rules (Auto-Enforced)

1. **Save Everything** — Timestamp every response
2. **Source Everything** — Peer-reviewed > official > blogs
3. **Smart Linking** — Same-domain wikilinks
4. **Append-Only** — Never delete
5. **Vault-First** — Reuse existing
6. **Skill Matching** — Only suggest what you know
7. **Device Aware** — Multi-device + sync
8. **Auto-Update** — Rules editable
9. **Transparent** — Show everything
10. **Non-Repudiation** — Complete timestamped log

## How It Works

### Learning

```
/hive-mind Explain machine learning

✓ Auto-detect: Learning context
✓ Search: Found 2 related notes
✓ Compose: Structured explanation
✓ Save: Learning/2026-04-19 - ML.md
✓ Source: 4 sources cited
✓ Link: [[Deep Learning]] [[Neural Networks]]
✓ Log: Session timestamp
```

### Projects

```
/hive-mind Build Python security tool

✓ Auto-detect: Project
✓ Check: Python in your skills? Yes
✓ Suggest: Python only (no impossible tools)
✓ Save: Projects/2026-04-19 - Tool.md
```

### Research

```
/hive-mind Research AI security threats

✓ Auto-detect: Research
✓ Search: Found 3 existing
✓ Compile: Findings + new research
✓ Source: 8 sources (papers first)
✓ Save: Research/2026-04-19 - Threats.md
```
